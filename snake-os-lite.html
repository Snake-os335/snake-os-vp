Snake OS Lite

Solo Arduino Mega, Ubuntu y Mac

Instalar en Linux

  1. Instala avrdude y Python 3 con pyserial: 
    sudo apt install avrdude python3 python3-serial
  2. Descarga el programa y el instalador de esta página, en la misma carpeta: 
    mkdir -p "$HOME/snake-os-lite"
cd "$HOME/snake-os-lite"
curl -fL -o snake-os-lite-mega2560.hex "http://127.0.0.1:8987/descargas/snake-os-lite.hex"
curl -fL -o snake-os-lite-cargar.sh "http://127.0.0.1:8987/descargas/snake-os-lite-cargar.sh"
  3. Haz ejecutable el instalador: 
    chmod +x snake-os-lite-cargar.sh
  4. Enchufa la Arduino Mega 2560 por USB. En Ubuntu aparece como /dev/ttyACM0 o /dev/ttyUSB0. Añade tu usuario al grupo dialout y vuelve a entrar: 
    sudo usermod -aG dialout $USER
  5. Ejecuta el instalador: 
    ./snake-os-lite-cargar.sh
  6. Cuando termine, abre el RTOS con el puerto que indique el instalador. En la Mega suele ser: 
    python3 -m serial.tools.miniterm /dev/ttyACM0 115200
    Escribe ayuda o rtos.
  7. Si Snake OS lo abres en el navegador contra el servidor de casa (no la nube), deja el puente USB apuntando a esa URL: 
    export SNAKEOS_WEB_BASE=http://127.0.0.1:8987
python3 snake-os-lite-local.py
    (En Mac el puerto serie suele ser /dev/cu.usbmodem*.)
